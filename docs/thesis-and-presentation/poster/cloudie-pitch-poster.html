Introduction

Cloud storage is where people keep their most important files, and where malware travels with them. A file that looks clean today may be recognised as malware next week, and files stored unencrypted are exposed the moment storage is breached. Cloudie scans every upload with several independent checks, encrypts it with AES-256 before it is stored, and keeps checking it after upload.

Our SolutionsSocial & Economic Impact

Layered Malware Analyzer

  • VirusTotal (~70 antivirus engines) is the primary check
  • AI Random Forest reads 32 structural features of PDFs
  • Structure checks catch macros, DDE, zip slip, fake extensions

AES-256 Encryption

  • Unique key and IV for every file
  • Only a SHA-256 hash of the key is stored, never the key
  • File hash re-checked after decryption (integrity)

QR Code Key

  • Key shown once as text, QR and key file, and emailed
  • Unlock by scanning the QR with the camera
  • Wrong key? Cloudie names the file it belongs to
INNOVATION

Retroactive Re-check

  • Asks VirusTotal again after upload, using only the file's fingerprint
  • No key needed, the file is never decrypted
  • Flagged later? File is quarantined and the user warned

Tamper-Evident Audit

  • Every action sealed in an HMAC-SHA256 hash chain
  • Edited or deleted entries show "Tampering detected"

Secure Access

  • Email verification and 2-step login code
  • Rate limits stop password guessing
  • The AI scanner is private, not on the internet
