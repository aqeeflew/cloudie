The idea

Signatures know the past.
Structure reads the file. Antivirus signatures only catch files someone has already seen. Cloudie also checks how a file is put together, so a disguised file is caught even when no engine has a signature for it yet. Every file is then encrypted before it is stored.

The problem

01
New malware has no signature yetSignature scanners miss files nobody has reported.
02
Attackers disguise filesA macro inside a .docx, invoice.pdf.exe, a ZIP hidden in a picture.
03
Stored files can leakFiles kept unencrypted are exposed if storage is breached.
